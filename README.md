 مشروع تقييم وتحسين جودة البيانات
(Data Quality Assessment and Improvement Project)

 1. نبذة عن المشروع
يهدف هذا المشروع إلى تقييم جودة البيانات وتحسينها باستخدام لغة Python ومكتبة Pandas، من خلال تطبيق مجموعة من إجراءات فحص البيانات واكتشاف الأخطاء ومعالجتها.

 2. أهداف المشروع
- فحص جودة البيانات وتحديد المشكلات.
- اكتشاف القيم المفقودة.
- اكتشاف السجلات المتكررة والمتشابهة.
- معالجة السجلات المكررة.
- اكتشاف القيم غير المنطقية.
- توحيد المسميات والتصنيفات.
- إنشاء تقرير نهائي لجودة البيانات.

 3. مؤشرات وفحوص جودة البيانات

اكتمال البيانات
التحقق من وجود القيم المفقودة في أعمدة البيانات.

التفرد
اكتشاف السجلات المكررة والمتشابهة ومعالجتها.

صحة البيانات 
التحقق من صحة القيم، مثل أعمار الموظفين والرواتب.

اتساق البيانات
توحيد أسماء الأقسام والتأكد من اتساق البيانات.

 4. نتائج معالجة البيانات

- عدد السجلات الأصلية: 12.
- عدد السجلات بعد معالجة التكرارات: 10.
- عدد السجلات المكررة المتبقية: 0.
- عدد مجموعات التشابه المكتشفة: 2.
- عدد السجلات المتشابهة المكتشفة: 4.
- اكتشاف عمر غير منطقي لموظف (150 سنة).
- تحويل العمر غير المنطقي إلى قيمة مفقودة للمراجعة.
- توحيد مسميات الأقسام.

 5. ملفات المشروع

- `data/employees.csv`: ملف البيانات الأصلي.
- `data/employees_cleaned.csv`: ملف البيانات بعد التنظيف والمعالجة.
- `reports/data_quality_report.csv`: التقرير النهائي لمؤشرات جودة البيانات.

 6. الأدوات والتقنيات المستخدمة

- Python
- Pandas
- Google Colab
- GitHub

 7. مراحل تنفيذ المشروع

1. تحميل البيانات.
2. فحص البيانات وتقييم جودتها.
3. اكتشاف السجلات المتشابهة.
4. معالجة السجلات المكررة.
5. فحص القيم المفقودة.
6. اكتشاف القيم غير المنطقية.
7. توحيد أسماء الأقسام.
8. التحقق النهائي من جودة البيانات.
9. إنشاء تقرير جودة البيانات وحفظ الملفات.

 8. الخلاصة

يقدم هذا المشروع تطبيقاً عملياً لمراحل تقييم وتحسين جودة البيانات، بدءاً من فحص البيانات واكتشاف المشكلات، مروراً بمعالجتها والتحقق من النتائج، وانتهاءً بإنتاج بيانات منظفة وتقرير يوثق مؤشرات الجودة.
